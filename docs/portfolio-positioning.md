# Employer-facing positioning

**Independent project:** Human–AI Collaboration Lab

This project explores human-in-the-loop AI evaluation, interaction design, correction handling, and context integrity.

## Transferable competencies to demonstrate
- Translating user needs into behavioral requirements and test scenarios.
- Identifying false assumptions, unsupported conclusions, and inconsistent responses.
- Designing evaluation rubrics with observable pass/fail criteria.
- Writing reproducible synthetic test cases and documenting limitations.
- Iteratively improving workflows using structured feedback.

## Relevant role families
AI quality/evaluation, trust and safety, conversational AI operations, prompt/workflow design, technical support quality, and AI-assisted operations.

## Claim boundaries
These are independent project activities, not evidence of paid ML engineering, professional model training, or measured improvements. Results and metrics should be added only after reproducible evaluation.
